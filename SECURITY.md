# Security Policy

## Supported Versions

Only the latest release is supported. Fixes land on `main` and ship in the next release;
there are no backports to earlier lines. See [CHANGELOG.md](CHANGELOG.md) for what is
released and what is pending.

| Version           | Supported          |
|-------------------| ------------------ |
| `main` (unreleased) | :white_check_mark: |
| 1.6.0 (latest release) | :white_check_mark: |
| < 1.6.0           | :x:                |

## Reporting a Vulnerability

Please report security issues privately via GitHub's
[private vulnerability reporting](https://github.com/status201/orca-dam/security/advisories/new).

Do **not** open a public issue for security-relevant findings.
